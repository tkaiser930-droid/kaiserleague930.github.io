Data & Backup

Where your league saves

Checking the active storage mode…

When the local project server is running, riders, teams, scores, trades, draft picks, settings, and schedule events are stored in data/league-data.json inside this project folder. This file is separate from the website pages and is not served directly to the browser.

Export a backup

Download a JSON backup of the saved league. Keep a backup before replacing project files, importing old data, or resetting the league.

Restore a backup

Choose a backup JSON file previously downloaded from this page. Restoring replaces the current league data, so export a backup first if you need to keep the current version.

Important

Run the site using npm start for project-file saving. If you open it with Live Server, the banner will say “Browser-only storage”; data then stays in that browser’s storage until you export it. The project database is local to this computer and is not a cloud or multi-computer database.

If your terminal reports that port 5500 is already in use, stop Live Server in VS Code first, then run npm start again.
